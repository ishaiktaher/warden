What is Warden?

One control point between agents and real systems.

Prompts can describe intent. Warden decides whether the current identity has verifiable authority to act.

01 / IDENTIFY

Know who is acting

Bind every call to a human principal, approved agent version, run, task and environment—not merely an API key.

02 / AUTHORIZE

Issue bounded authority

Short-lived signed capabilities specify exact actions and resources. Delegation can only make them narrower.

03 / EXECUTE

Keep credentials at the gateway

After policy permits the action, Warden resolves and injects the credential, executes the connector and redacts the audit record.

Authority, custody and evidence in one gateway.

ID

Runtime-bound identity

Principal, agent, run, task and approved manifest version travel together through the action lifecycle.

⌁

Signed capabilities

RS256 authority is short-lived, revocable, resource-scoped and protected against transfer between runs.

↳

Safe delegation

Manager agents can delegate to specialists without granting actions or resources they never held.

✓

Layered policy

Platform, tenant, agent, connector and credential policies only narrow authority and fail closed.

•••

Credential isolation

OAuth and managed secrets remain in your selected vault and are injected only at execution time.

#

Tamper-evident audit

A redacted hash chain records issuance, delegation, approvals, revocations, calls and outcomes.
